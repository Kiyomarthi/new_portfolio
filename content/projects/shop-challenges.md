# چالش اصلی

::warning
**وضعیت پروژه:** وبسایت این پروژه دیگر در دسترس نیست و شما به پروتوتایپ آن متصل می شوید.
::

**فروشگاه ویاناسیستم** یک پروژه فروشگاهی بود که با هدف طراحی و پیاده‌سازی یک تجربه کاربری مناسب برای خرید آنلاین توسعه داده شد.

تمرکز اصلی پروژه روی پیاده‌سازی رابط کاربری فروشگاه و ساخت صفحات و بخش‌های موردنیاز یک فروشگاه اینترنتی بود.

## بخش‌های اصلی

در پروژه بخش‌های مختلف فروشگاه از جمله:

- صفحه اصلی
- لیست محصولات
- جزئیات محصول
- دسته‌بندی محصولات
- سبد خرید
- بخش‌های مختلف رابط کاربری فروشگاه

پیاده‌سازی شدند.

## رابط کاربری

رابط کاربری پروژه با استفاده از **Vuetify** و اکوسیستم Vue توسعه داده شد.

هدف، ایجاد یک رابط کاربری منسجم و قابل استفاده برای صفحات مختلف فروشگاه بود.

همچنین ساختار Componentها به شکلی پیاده‌سازی شد که بخش‌های مشترک رابط کاربری قابلیت استفاده مجدد داشته باشند.

## نتیجه

این پروژه تجربه‌ای عملی در زمینه توسعه یک **E-commerce Frontend** با استفاده از **Nuxt.js، Vue.js و Vuetify** بود و باعث شد با ساختار صفحات و Componentهای موردنیاز یک فروشگاه اینترنتی بیشتر آشنا شوم.
